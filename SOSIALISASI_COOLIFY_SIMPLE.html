01 • LATAR BELAKANG & KEUNGGULAN

Mengapa Memilih Coolify?

Solusi cerdas menggantikan deployment manual & menghemat biaya cloud

02 / 06
💰
Hemat Biaya 100%
Berjalan di server VM private Proxsis (on-premise). Tidak ada biaya sewa dyno bulanan seperti Heroku ($7–$25/app) atau tagihan tak terduga AWS.
⚡
Otomatis Tanpa Ribet
Tidak perlu utak-atik Nginx, Caddyfile, atau SSL manual. Coolify otomatis mengatur sertifikat HTTPS dan domain *.connect.proxsis.com.
🤖
Siap untuk AI Agent
Memiliki REST API yang matang. Cukup berbicara dengan AI Agent (Antigravity/Claude Code), aplikasi langsung terdeploy tanpa menyentuh terminal server.

03 • OTOMASI AI AGENT

Cara Deploy Aplikasi dengan AI

Satu perintah percakapan, aplikasi langsung online

04 / 06

Tool yang Didukung Penuh (Tier 1):
• Google Antigravity (Rekomendasi Utama internal)

04 • OPERASIONAL INFRA

Maintenance Coolify oleh Tim Infra

4 pilar utama pemeliharaan server agar sistem selalu stabil

05 / 06
🧹
1. Auto-Prune Docker
Jadwalkan cron job pembersih image dan builder cache gantung:
docker image prune -af --filter "until=72h"
docker builder prune -af
💾
2. Backup Rutin
Snapshot harian direktori internal Coolify dan seluruh persistent storage:
/data/coolify/
DB Dump harian ke S3
🔄
3. Update Versi
Pembaruan versi core Coolify secara aman tanpa downtime kontainer:
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
📊
4. Monitoring Resource
Pantau RAM & disk Proxmox VM (192.168.10.21). Pastikan disk di bawah 80% & batas memory per app 512MB–1GB.
